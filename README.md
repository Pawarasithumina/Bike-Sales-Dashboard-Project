# Bike Sales Dashboard Project

##  Project Overview

**Bike Sales Dashboard Project** is an Excel-based data analytics and business intelligence project developed to analyze bike sales performance using structured sales data.

The project follows a complete data analysis workflow, starting with **raw data preparation and cleaning**, followed by **data transformation, Pivot Table analysis, visualization, and interactive dashboard development**.

The dashboard provides a summarized view of bike sales performance and allows users to explore important business metrics such as **sales trends, revenue, product/model performance, and category-level performance**.

The project demonstrates how Microsoft Excel can be used to transform raw sales records into an interactive dashboard that supports data exploration and business decision-making.

---

##  Project Objectives

The main objectives of this project were to:

* Clean and organize raw bike sales data.
* Prepare the dataset for accurate analysis.
* Analyze sales performance across different bike models and categories.
* Identify top-performing bike models.
* Analyze revenue and sales trends.
* Compare sales performance across different categories.
* Create Pivot Tables to summarize key business metrics.
* Develop an interactive Excel dashboard.
* Present sales insights through clear and effective visualizations.

---

##  Data Preparation

The project begins with the preparation of the raw bike sales dataset.

The data preparation process includes:

##  Dashboard Overview

The final dashboard provides an interactive summary of the bike sales dataset.

### 1. Top-Selling Bike Models

The dashboard identifies bike models with higher sales performance.

This allows users to compare different models and understand which products contribute more to overall sales.

### 2. Revenue Analysis

Revenue-related metrics are visualized to provide an overview of financial performance.

The dashboard allows users to examine how revenue changes across different products, categories, or time periods represented in the dataset.

### 3. Sales Trends

Sales performance is analyzed across the available time periods in the dataset.

This helps identify changes and patterns in sales activity over time.

### 4. Category Performance

Bike sales are compared across different product categories.

This provides an overview of which categories contribute more significantly to sales performance.

### 5. Interactive Dashboard

The final dashboard combines multiple charts and summarized metrics into a single interface.

Users can interact with the available filters and visualizations to explore specific areas of the sales data.
